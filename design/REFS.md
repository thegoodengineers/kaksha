# Design references (researched before any UI, 10 Nov)

| Site | What we took | Where we use it |
|---|---|---|
| godly.website | Now redirects to recent.design (`?ref=godly`), so the two are one source | - |
| recent.design (`refs/recent-design-feed.jpg`) | An interface card drawn as concentric orbits with small labelled nodes; dark cards that hold one figure | The orbit rings behind the page title; one big risk number per event card |
| landdding.com (`refs/landdding-stat-strip.jpg`) | Stat strip: small-caps label over a number, hairline dividers, no boxes; a status line led by a coloured dot ("UPDATED DAILY") | Results strip (missed events, unnecessary manoeuvres, L score); the recommendation line with a coloured dot |
| landdding.com (`refs/landdding-cards.jpg`) | "Fix what's drifting" monitoring card: quiet chrome, one bright state colour | Only state gets colour: amber = plan a manoeuvre, teal = monitor |
| mobbin.com (`refs/mobbin-403.jpg`) | Blocked to automated browsers (403). Check real ops/monitoring dashboards by hand before the prototype round | Event timeline and slider |

Rule we kept: copy patterns (layout, spacing, hierarchy), never logos, copy or paid assets.
